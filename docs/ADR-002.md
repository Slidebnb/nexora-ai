# ADR-002: Übernahme von Quellcode aus den Masterplan-Repositories

- Status: angenommen · Datum: 2026-10-31 · ersetzt Punkt 2 von ADR-001

## Kontext
ADR-001 hat entschieden, keinen Fremdcode zu kopieren, weil zwei Repositories keine LICENSE-Datei haben. Der Projektinhaber hat ausdrücklich angewiesen, den Code zu übernehmen. Nach seiner Angabe hat er die Zustimmung der Autoren eingeholt, und beide READMEs nennen die MIT-Lizenz.

## Entscheidung
1. Visuelle Komponenten werden portiert und angepasst: jenman `AiCore`, evil-ai-viz `MatrixRain`, `ScanLines`, `DataFlowLines` und `HexStream`, cyberpunk-dashboard Sidebar, Breadcrumb und Feed-Stil.
2. Jede portierte Datei trägt einen Herkunftsvermerk (Repo, Commit, Pfad, Lizenz, Änderungen). Alle Übernahmen sind in `THIRD_PARTY_NOTICES.md` aufgeführt, zusammen mit dem MIT-Text.
3. Weiterhin ausgeschlossen bleibt, was der Masterplan selbst verbietet: Tracking, Fingerprinting, vorgetäuschte Systemeingriffe, Fake-Metriken und externe Feeds.
4. Alle portierten Anzeigen werden mit echten Event-Daten gespeist. Zufallswerte bleiben nur als rein dekorative Bewegung erhalten (Zeichen im Regen, Partikelstreuung).
5. ClawBridge (Apache-2.0/MIT) und browser-use (MIT) werden im Worker eingesetzt (Phase 2). Übernommener Code wird nach Apache-2.0 §4 gekennzeichnet.

## Konsequenzen
+ Die Optik entspricht den Vorlagen aus dem Masterplan.
− Restrisiko bei den Repos ohne LICENSE-Datei, falls keine schriftliche Zustimmung archiviert wird.
