# ADR-001: Eigene Codebasis mit selektiver Inspiration statt Repo-Merge

- Status: angenommen · Datum: 2026-10-31

## Kontext
Vier Quell-Repos (siehe SOURCE_AUDIT.md). Zwei haben keine LICENSE-Datei, eines hat widersprüchliche Lizenzdateien. Die UI-Repos zielen auf drei verschiedene Runtimes: Vite+Convex, einen Replit-Workspace und Next.js. ClawBridge besteht aus einem Monolithen mit 14 765 Zeilen und einem Server mit `allow_origins=["*"]` ohne Authentifizierung.

## Entscheidung
1. Eine neue Codebasis (Repository `Slidebnb/nexora-ai`) mit Electron + React/Vite (Renderer) und einem Python-FastAPI-Sidecar.
2. Phase 1 enthält keinen kopierten Fremdcode. Visuelle Komponenten werden neu geschrieben, die Konzepte sind dokumentiert.
3. Der Worker wird schlank neu implementiert. Muster aus ClawBridge (Engine-Interface, Safety-Klassen, Redaktion, Schemas) werden konzeptionell übernommen, Netzwerk- und Remote-Teile nicht.
4. Der Event-Vertrag ist die einzige Wahrheitsquelle für den UI-Status. Der Demo-Modus erzeugt Events mit `source:'demo'` über denselben Reducer.

## Konsequenzen
+ Saubere Lizenzlage, kleinere Angriffsfläche, ein Toolchain-Stack (pnpm, Vite, TS).
− Mehr Eigenaufwand für Visualisierungen und Worker.
Offen: Lizenzklärung mit den Autoren von evil-ai-viz und cyberpunk-dashboard, falls später doch Code übernommen werden soll.
