# ADR-003: Auslieferung, Signatur, Updates und Telemetrie

- Status: angenommen · Datum: 2026-10-31

## Installer
- **Windows:** NSIS-Installer pro Benutzer, ohne Administratorrechte (`app/electron-builder.yml`). Der Python-Worker wird mit PyInstaller als Ordner-Variante gebündelt. Die Ordner-Variante startet schneller und löst seltener Fehlalarme bei Virenscannern aus als `--onefile`.
- **Build:** ausschließlich über die CI (`.github/workflows/ci.yml`, Job „Windows-Installer“) auf einem echten Windows-Rechner. Die CI führt alle Tests aus, baut Sidecar und Installer, startet die gepackte App und lädt den Installer als Artefakt hoch.
- **Abnahme laut Masterplan:** Installation auf einem frischen Windows ohne Entwicklerwerkzeuge, danach Onboarding und ein erster echter Erfolg. Das prüft eine Person manuell, Checkliste in `docs/PILOT.md`.

## Code-Signatur
- Ohne Signatur zeigt Windows SmartScreen eine Warnung an. Für den Verkauf ist ein **OV- oder EV-Code-Signing-Zertifikat** nötig. EV baut die SmartScreen-Reputation sofort auf, OV erst nach und nach.
- Hinterlegt wird das Zertifikat nur als GitHub-Secrets (`WIN_CSC_LINK`, `WIN_CSC_KEY_PASSWORD`). electron-builder signiert automatisch, sobald diese Secrets gesetzt sind. Zertifikate gehören nie ins Repository.

## Updates
- Der Masterplan sieht Auto-Updates erst nach einer stabilen MVP-Basis vor. **Deshalb ist derzeit kein Auto-Update aktiv** (`publish: null`).
- Geplanter Weg: `electron-updater` mit einem eigenen statischen Update-Server (oder GitHub Releases eines privaten Release-Repos), nur signierte Builds. Der Nutzer wird gefragt und entscheidet selbst, wann neu gestartet wird. Laufende Vorgänge blockieren den Neustart.
- Für Migrationen gilt: Die Worker-Datenbank migriert vorwärts (getestet, v1→v2). Vor jeder Migration soll eine Sicherungskopie `nexora.db.bak` entstehen (offen).

## Telemetrie
- **Diese Version erhebt und sendet keinerlei Nutzungs- oder Absturzdaten.**
- Falls später Telemetrie dazukommt: nur per ausdrücklichem Opt-in in den Einstellungen, nur aggregierte Zähler (gestartete und erfolgreiche Vorgänge je Workflow), keine Inhalte, Pfade oder Schlüssel. Auch die Funnel-Messung aus §11 erfolgt nur mit Zustimmung.
